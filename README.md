# MAL Clone - اُانیمه کلون

این یک کلون از سایت MAL (MyAnimeList) است که امکان مشاهده اُانیمه‌ها و اطلاعات مرتبط با آن‌ها را فراهم می‌کند.

## ساختار پروژه

- `index.html` - صفحه اصلی وب
- `style.css` - فایل سبک‌ها برای ظاهر و روانی صفحات
- `src/`  - کدهای منبع React
  - `App.jsx` - اصلی‌ترین فایل React
  - `main.jsx` - نقطه ورود برنامه
- `public/data/` - فایل‌های داده اُانیمه
- `assets/covers/` - تصاویر جلد اُانیمه
- `dist/` - نسخه ساخته شده پروژه (فایل‌های انتشاری)

## ویژگی‌ها

- نمایش لیست اُانیمه‌ها
- مشاهده جزئیات هر اُانیمه
- نمایش تصاویر جلد اُانیمه

## استفاده

برای راه‌اندازی توسعه:
```
npm install
npm run dev
```

برای ساخت پروژه:
```
npm run build
```

## وابستگی‌ها

- React
- Axios (برای درخواست‌های HTTP)
- Swiper (برای اسلایدر عکس)
