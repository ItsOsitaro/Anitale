- پس‌زمینه: `color-mix(in oklch, var(--card) 80%, transparent)` + `backdrop-filter: blur(20px) saturate(1.6)` + `box-shadow: inset 0 0 0 1px color-mix(in oklch, var(--border) 70%, transparent), 0 18px 36px -14px #4f2e4466`.

| ترتیب (راست به چپ) | برچسب | مسیر |
