### ۲.۲ تایپوگرافی (Vazirmatn)

| کاربرد | اندازه / وزن / line-height |
|---|---|
| عنوان hero | 27px / 800 / 1.35 |
| عنوان صفحه (مثلاً «انیمه») | 24px / 800 |
| عنوان سکشن | 17px / 800 |
| عنوان کارت در ریل و لیست | 12.5–14px / 700 / 1.5–1.6 |
| متن خلاصه‌ی داستان | 14px / 400 / **2.0** (فارسی نیاز به فاصله‌ی بیشتر دارد) |
| متن کمکی/متا | 11–12.5px / 400–600، رنگ `--muted-foreground` |
| برچسب tab bar | 10.5px / 700 |

متن طولانی عرضش بیشتر از عرض موبایل نمی‌شود و نیازی به محدودیت اضافه نیست. لیبل‌ها را فاصله‌دار یا بزرگ‌حروف نکن و بالای عنوان‌ها «برچسب کوچک» (eyebrow) نگذار.
